# 농부였던 내가 오늘부터는 용사?! (농부용사)

> 마왕 때문에 흉년이라고? 그럼 내가 직접 마왕을 쓰러뜨리면 되지!

텍스트 기반 던전 도장깨기 RPG 게임입니다.
객체를 조건으로 활용하여 함수가 호출되는 구조를 학습하기 위한 팀 프로젝트입니다.

---

## 스토리

마왕이 세상을 지배하게 된 후, 늘 구름 낀 날씨가 계속되어 흉년이 이어졌습니다.
계속된 흉년에 화가 난 농부는 직접 마왕을 쓰러뜨리기 위해 던전 도장깨기에 나섭니다.

---

## 게임 클리어 조건

모든 던전의 **토벌증서**를 수집한 뒤, **마왕**을 쓰러뜨리면 게임 클리어!

---

## 게임 플레이

### 메인 화면

화면 상단에 플레이어 캐릭터의 이름, HP, MP, 경험치를 항상 표시하여 현재 상태를 한눈에 파악할 수 있습니다.
그 아래에 메뉴 선택지가 배치되어, 원하는 기능을 번호 입력으로 이용할 수 있습니다.

```
=============== Player's Status ===============
 ~
================================================
 <MENU>
 1. 던전 입장
 2. 스테이터스
 3. 인벤토리
 4. 장비
 5. 포션 제작
 6. 상점 이용
 0. 게임 종료
================================================
 Choose:

 Result Output
```

### 1. 던전 & 전투

몬스터별 던전이 존재하며, 플레이어가 원하는 던전을 선택하여 진입합니다.

**던전 선택**

```
=============== Player's Information ===============
 ~
====================================================
 <Dungeon Menu>
 1. Slime Dungeon
 2. Zombie Dungeon
 3. Golem Dungeon
====================================================
 Choose:

 Result Output
====================================================
```

**던전 진행**

던전 내부에서는 아래 메뉴를 통해 진행합니다.

```
=============== Player's Information ===============
 ~
====================================================
 <Dungeon Progression Menu>
 1. Moving forward
 2. Inventory
 3. Dungeon Escape
====================================================
 Choose:

 Result Output
====================================================
```

- **Moving forward** — 앞으로 진행하면 랜덤 이벤트가 발생합니다. (몬스터 조우, 보물상자 발견, 던전 상인 등)
- **Inventory** — 던전 내에서 인벤토리를 열어 아이템을 사용할 수 있습니다.
- **Dungeon Escape** — 던전을 탈출하여 메인 메뉴로 돌아갑니다.

### 2. 스테이터스

플레이어 캐릭터의 전체 스탯을 확인할 수 있습니다.
상단 요약 영역에는 이름, 직업, 레벨 + 현재 경험치, 현재 체력, 현재 마나만 표시됩니다.

```
=============== Player's Information ===============
 ~
====================================================
 <Player's Status>
 Job: ...

 HP: current HP / Max HP    MP: current MP / Max MP
 EXP: current EXP / Max EXP

 ATK: current Attack        DEF: current Defence
 CRIT: current Critical     SPD: current Speed
====================================================
 Return to the main menu by Input 0
 user Input:
====================================================
```

### 3. 인벤토리

플레이어 정보 아래에 소지 아이템 목록이 출력됩니다.
번호를 입력하면 해당 아이템이 즉시 사용되어 캐릭터에 효과가 반영됩니다.
사용 불가능한 아이템을 선택하면 안내 문구가 출력되며, `0`을 입력하면 이전 메뉴로 돌아갑니다.

```
=============== Player's Information ===============
 ~
====================================================
 <Inventory>
 0. Return to menu
 1. ...
 2. ...
 3. ...
====================================================
 Choose:

 Result Output
====================================================
```

### 4. 장비

장비를 착용하면 캐릭터 스탯이 강화됩니다.
현재 착용 중인 장비는 UI에 별도 표시되며, 착용 중인 장비를 다시 선택하면 해제, 미착용 장비를 선택하면 착용됩니다.

```
=============== Player's Information ===============
 ~
====================================================
 <Equipment>
 0. Return to menu
 1. ...
 2. ...
 3. ...
====================================================
 Choose:

 Result Output
====================================================
```

### 5. 포션 제작

던전에서 획득한 재료를 사용하여 포션을 제작할 수 있습니다.
제작 가능한 포션 목록에서 원하는 포션을 선택하면, 필요한 재료가 소모되고 포션이 인벤토리에 추가됩니다.

```
=============== Player's Information ===============
 ~
====================================================
 <Potion Crafting>
 0. Return to menu
 1. ...
 2. ...
 3. ...
====================================================
 Choose:

 Result Output
====================================================
```

### 6. 상점

골드를 사용하여 아이템을 구매하거나, 소지한 아이템을 판매할 수 있습니다.

```
=============== Player's Information ===============
 ~
====================================================
 <Shop>
 0. Return to menu
 1. ...
 2. ...
 3. ...
====================================================
 Choose:

 Result Output
====================================================
```
