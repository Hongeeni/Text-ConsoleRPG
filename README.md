# 농부였던 내가 오늘부터는 용사?! (농부용사)

텍스트 기반 던전 도장깨기 RPG 게임입니다.
객체를 조건으로 활용하여 함수가 호출되는 구조를 학습하기 위한 팀 프로젝트입니다.

---

## 스토리
<details>
<summary> 스토리 접기/펼치기</summary>

========================================

마왕이 세상을 지배한 이후

세상은 끝없는 흉년에 빠졌습니다.

햇빛은 사라지고 농작물은 모두 말라 죽었고,
농부였던 당신의 밭도 결국 황무지가 되었습니다.

"농사가 안 된다면...
마왕을 쓰러뜨리면 되는 거 아닌가?"

그렇게 당신은 낫을 들고
마왕을 향한 여정을 시작합니다.

하지만 마왕에게 가는 길에는
수많은 던전과 강력한 몬스터들이 기다리고 있습니다.

모든 던전을 돌파하고
세상에 다시 풍년을 되찾으세요!

========================================
</details>

## 게임 클리어 조건

모든 던전의 **토벌증서**를 수집한 뒤, **마왕**을 쓰러뜨리면 게임 클리어!

## 게임 플레이

<details>
<summary>게임 플레이 접기/펼치기</summary>
 
### 조작 방법

<details>
<summary>조작 방법 접기/펼치기</summary>
 
======================== 조작 안내 ========================
메뉴는 번호를 입력해 선택합니다.

던전에서 전진하면 몬스터, 보물상자, 상점,
제단, 생명의 샘, 보스방 중 하나를 만납니다.

전투는 라운드마다 행동 토큰 2개를 받습니다.
  일반 공격 / 스킬 공격 : 토큰 2
  아이템 사용           : 토큰 1

각 던전 보스방에는 문제가 있습니다.
보물상자에서 나오는 [정체를 알 수 없는 종이]가 힌트입니다.
인벤토리에서 종이의 설명을 확인하세요.

던전 3곳을 토벌해 [토벌 증서] 3장을 모으면
마왕의 성에 들어갈 수 있습니다.
===========================================================
</details>

### 메인 화면

<details>
<summary>메인화면 설명 접기/펼치기</summary>
화면 상단에 플레이어 캐릭터의 이름, HP, MP, 경험치를 항상 표시하여 현재 상태를 한눈에 파악할 수 있습니다.
그 아래에 메뉴 선택지가 배치되어, 원하는 기능을 번호 입력으로 이용할 수 있습니다.

```
=======================================================
 야옹  Lv.1 [Farmer]   목숨 3/3   골드 175
 HP ##################.. 185/200
 MP #################### 200/200
 EXP 20/100
=======================================================

-------------------------------------------------------
[1] 던전  [2] 스탯  [3] 인벤토리  [4] 장비  [5] 포션 제작  [6] 상점  [0] 종료
선택:

```
</details>

## 1. 던전 & 전투

몬스터별 던전이 존재하며, 플레이어가 원하는 던전을 선택하여 진입합니다.

<details>
<summary>던전/전투 접기/펼치기</summary>

**던전 선택**

<details>
<summary>던전 선택 접기/펼치기</summary>

```

[1] 슬라임 던전   [2] 언데드 던전   [3] 골렘 던전
[4] 마왕의 성     [0] 돌아가기
선택:

```
</details>

### **던전 진행**

던전 내부에서는 아래 메뉴를 통해 진행합니다.

<details>
<summary>던전 진행 상세설명 접기/펼치기</summary>

```
=======================================================
 [슬라임 던전]   야옹 Lv.1 [Farmer]   목숨 3   골드 175
 HP ##################.. 185/200   MP 200/200
=======================================================


-------------------------------------------------------
[1] 전진   [2] 인벤토리   [0] 탈출
선택:
```
</details>

### **전진** — 앞으로 진행하면 랜덤 이벤트가 발생합니다. (몬스터 조우, 보물상자 발견, 던전 상인 등)

<details>
<summary>던전 이벤트 상세 설명 접기/펼치기</summary>

*몬스터 조우* 랜덤한 몬스터와 조우하고, 바로 전투에 돌입합니다. 승리 시 골드와 아이템을 획득하고 패배시 목숨이 차감됩니다.

```
 --- 전투 개시 ---
 [작은 슬라임] 등장!  체력 80 공격력 15 방어력 5
-------------------------------------------------------
[1] 공격   [2] 스킬(MP 20)   [3] 아이템      토큰 2
선택:
```
#### *제단* - 능력치를 획득하거나, 잃을 수 있습니다.

```
[1] 제단을 만진다   [0] 지나친다
선택:
```

#### *생명의 샘* - HP와 MP를 회복할 수 있습니다.

```
 생명의 샘에서 몸을 씻었다.  HP +58 MP +294
-------------------------------------------------------
[1] 전진   [2] 인벤토리   [0] 탈출
선택:
```

#### *보물상자* - 골드와 아이템을 획득할 수 있습니다. 획득한 아이템은 메인메뉴에서 장착이 가능합니다.

```
 낡은 보물상자를 발견했다!  골드 80 획득
   얇은 방패 x1
-------------------------------------------------------
[1] 전진   [2] 인벤토리   [0] 탈출
선택:
```

#### *던전 상인* - 던전에서만 만날 수 있는 상인입니다. 던전마다 다른 상인이 등장하며, 가격은 상이합니다.

```
=========================================================
[슬라임 상인]
슬라임슬라임
---------------------------------------------------------
[번호][이름]              [갯수]  [가격]
---------------------------------------------------------
1     힐링 포션           5       75G
2     마나 포션           5       75G
---------------------------------------------------------
골드: [788]
---------------------------------------------------------
[아이템 이름: 구매] [[1]: 아이템 판매] [[2]: 장비 판매] [[0]: 뒤로]
```
</detail>

####  **인벤토리** — 던전 내에서 인벤토리를 열어 아이템을 사용할 수 있습니다.
#### **탈출** — 던전을 탈출하여 메인 메뉴로 돌아갑니다. (목숨과 전리품을 잃지 않습니다.)

#### **보스룸** - 선택을 통해 보스룸에 입장할 수 있습니다. 

<details>
<summary>보스룸 상세설명 접기/펼치기</summary>
 
```
 커다란 문을 발견했다. 보스방으로 갈 수 있다.
-------------------------------------------------------
[1] 전진   [2] 인벤토리   [3] 보스룸   [0] 탈출
선택:
```

**수수께끼** - 보스룸에 입장 시, 던전별로 수수께끼가 나타나며 수수께끼의 답을 맞춰야 던전의 보스와 전투가 진행됩니다.
(인벤토리에서 정체를 알 수 없는 모 아이템에서 힌트를 확인할 수 있습니다.)

```
=========================================
    거대한 문 앞에 글귀가 새겨져 있다.

    "흩어진 세 장의 종이가 가리키는
             정답을 말하라."
=========================================
정답:
```
</details>

## 2. 스테이터스

플레이어 캐릭터의 전체 스탯을 확인할 수 있습니다.
상단 요약 영역에는 이름, 직업, 레벨 + 현재 경험치, 현재 체력, 현재 마나만 표시됩니다.

<details>
<summary>스테이터스 상세설명 접기/펼치기</summary>

```
=======================================================
  야옹   [Farmer]
-------------------------------------------------------
  레벨      1 / 10
  목숨      3 / 3
  경험치    90 / 100
-------------------------------------------------------
  HP        #############.......  130 / 200
  MP        ##############......  140 / 200
-------------------------------------------------------
  공격력    30
  방어력    10
  치명타    10%
  속도      10
-------------------------------------------------------
  골드      255
  스킬 소모 MP 20
=======================================================
계속하려면 아무 키나 누르십시오 . . .
```
</details>

#### 성장 

**레벨업** - 레벨이 상승할 경우 HP, MP가 모두 회복되며 능력치가 전체적으로 상승합니다.
**전직** - 플레이어는 농부로 시작하지만, 성장과 동시에 전사 또는 마법사로 전직할 수 있습니다.

<details>
<summary>전직 접기/펼치기</summary>

```
=========================================
  농부의 손에 낯선 힘이 깃든다.
  당신은 더 이상 농부가 아니다.
-----------------------------------------
[1] 전사
      방어력 +5, 최대 HP +100
      레벨업마다 방어력 +2, 최대 HP +50
[2] 마법사
      공격력 +3, 최대 MP +100
      레벨업마다 공격력 +2, 최대 MP +50
      스킬 위력 3배
=========================================
선택:
```

</details>


## 3. 인벤토리

플레이어 정보 아래에 소지 아이템 목록이 출력됩니다.

<details>
<summary>인벤토리 상세 설명 접기/펼치기</summary>

번호를 입력하면 해당 아이템이 즉시 사용되어 캐릭터에 효과가 반영됩니다.
사용 불가능한 아이템을 선택하면 안내 문구가 출력되며, `0`을 입력하면 이전 메뉴로 돌아갑니다.

```
============== 인 벤 토 리 ==============
==========================================================================
[번호][이름]                        [개수]  [설명]
--------------------------------------------------------------------------
1     힐링 포션                     3       HP를 회복합니다. (+50)
2     마나 포션                     2       MP를 회복합니다. (+50)
3     슬라임 부산물                 3       슬라임의 조각입니다.
4     붉은 허브                     1       포션 제작에 사용됩니다.
==========================================================================
[아이템 이름: 사용] [0: 돌아가기]
선택:
```

</details>

## 4. 장비

장비를 착용하면 캐릭터 스탯이 강화됩니다.

<details>
<summary>장비 상세 설명 접기/펼치기</summary>
 
현재 착용 중인 장비는 UI에 별도 표시되며, 착용 중인 장비를 다시 선택하면 해제, 미착용 장비를 선택하면 착용됩니다.

```
=============== Player's Information ===============
 ~
====================================================
 <Equipment>
 0. Return to menu
 1. ...
 2. ...
 3. ...
====================================================
 Choose:

 Result Output
====================================================
```
</details>
